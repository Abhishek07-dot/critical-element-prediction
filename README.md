# Critical Element Prediction Model

This project predicts critical element concentration using:

- XGBoost
- Residual Kriging
- DEM Terrain Variables
- Google Earth Engine

## Features

- Spatial prediction
- Terrain integration
- Uncertainty estimation
- Multi-coordinate prediction

## Technologies Used

- Python
- XGBoost
- PyKrige
- Scikit-learn
- Google Earth Engine

## Files

- critical_element_prediction.py → Main model
- Lithium_with_DEM.csv → Dataset with terrain variables
